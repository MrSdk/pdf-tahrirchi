Tekshirilmoqda…

Ollama'ga ulanib bo'lmadi. Qo'lda tahrirlash to'liq ishlaydi. AI uchun:

  1. Ollama ishlab turganini tekshiring: ollama list
  2. Docker konteyneri unga yeta olishi uchun terminalda: 
    sudo systemctl edit ollama
    ochilgan faylga shuni yozing va saqlang: 
    [Service]
Environment="OLLAMA_HOST=0.0.0.0"
    keyin: 
    sudo systemctl restart ollama
  3. Tarmoq devori (ufw) yoqilgan bo'lsa, konteynerga ruxsat bering: 
    sudo ufw allow in on br-pdftahrir to any port 11434 proto tcp
  4. Shu yerda «yangilash»ni bosing.
